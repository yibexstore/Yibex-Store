# CON CCEO STILOS_RD

Proyecto organizado automáticamente a partir de un HTML existente.

## Estructura

- `index.html`: página principal.
- `css/`: estilos extraídos de las etiquetas `<style>`.
- `js/`: scripts JavaScript extraídos, conservando su orden de aparición.
- `assets/`: carpeta para imágenes, fuentes e iconos.
- `components/`: espacio para componentes HTML que se separen manualmente.
- `pages/`: espacio para páginas adicionales.
- `CON CCEO STILOS_RD-original.html`: copia de seguridad del HTML original.

## Resultado de la extracción

- Bloques CSS extraídos: 1
- Scripts JavaScript extraídos: 2
- Scripts no ejecutables conservados dentro del HTML: 1

## Cómo probarlo

Abre `index.html` en tu navegador. Si la página usa `fetch`, módulos ES,
rutas especiales o carga de archivos externos, ejecútala mediante un servidor
local (por ejemplo, la extensión Live Server de Visual Studio Code).

## Importante

Esta primera organización evita dividir automáticamente el marcado HTML
en secciones sin conocer las dependencias de la tienda. No muevas ni renombres
recursos hasta comprobar las rutas. Prueba el menú, filtros, búsqueda, carrito,
formularios y demás funciones antes de publicar en GitHub Pages.
